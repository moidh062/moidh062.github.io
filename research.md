<h2>Undergraduate Thesis</h2>
<ul>
  <li>
    <b>Deep Learning Models for Tuberculosis Detection from Chest X-rays</b><br>
    Department of Biomedical Engineering, BUET | Oct 2023 – Mar 2025<br>
    <i>Supervisor: Prof. Dr. Taufiq Hasan</i><br>
    Developed and evaluated CNN-based pipelines for automated TB diagnosis from chest radiographs. Focused on generalization, clinical interpretability, and bounding-box-free localization.<br>

<h2>Research Projects</h2>
<ul>
  <li>
    <b>ViewRetina: Diabetic Retinopathy and Glaucoma Detection Using Deep Learning</b><br>
    Capstone Project | July 2022 – Nov 2023<br>
    <i>With Tahia Ifreet and Abrar Ahmed | Supervised by Asst. Prof. Shams Nafisa Ali</i><br>
    Developed a low-cost, portable smartphone ophthalmoscope to enhance retinal screening accessibility in low-resource settings. The project involved designing an image processing pipeline to compute the cup-to-disc ratio (CDR), a critical biomarker for early glaucoma detection, using adaptive thresholding and histogram smoothing for precise segmentation of the optic disc and cup. A CNN-based deep learning model was also trained for automated diabetic retinopathy classification from fundus images, incorporating Grad-CAM for clinical interpretability. Tested and validated the pipeline using publicly available ophthalmology datasets.<br>
    <a href="https://github.com/moidulhasan/ViewRetina-DR"><div class="color-button">Learn More</div></a>
  </li>
</ul>

<h2>Research Implementations</h2>
<ul>
  <li>
    <b>Deep Learning-Based Diabetic Retinopathy Classification</b><br>
    Deep Learning Project | July 2022 – Feb 2023<br>
    Executed a deep learning multiclass classification model based on a published research framework for referable diabetic retinopathy detection using retinal fundus images. Integrated Grad-CAM-based visual saliency maps to highlight lesion regions for clinical interpretability. Developed and deployed a web application to enable image-based diagnosis, improving accessibility for remote screening and potential clinical use.<br>
    <a href="https://github.com/moidulhasan/ViewRetina-DR"><div class="color-button">Learn More</div></a>
  </li>
</ul>
